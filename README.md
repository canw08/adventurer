# ⚔️ Adventurer's Guild | 校园冒险者公会

### Turning Volunteer Work into Adventures

**A gamified high school volunteering platform inspired by the Adventurers' Guild concept in anime and fantasy worlds.**

**Status:** Discontinued · Public for educational and portfolio purposes

---

## 🌟 About the Project | 项目介绍

**What if volunteering at school felt like going on an adventure?**

Adventurer's Guild was created to reimagine how high school students participate in volunteer activities.

Inspired by the adventurers' guilds commonly seen in anime and fantasy stories, the project transforms traditional school volunteering opportunities into **quests** that students can discover, accept, and complete in exchange for rewards.

Beyond making volunteering more engaging, the platform was also designed to help schools organize volunteer activities and keep track of students' volunteer service hours.

### 项目背景

Adventurer's Guild（校园冒险者公会）是一个面向高中校园的**游戏化志愿服务管理平台**。

在传统的校园志愿服务中，学生往往需要通过通知、表格等方式了解和报名志愿活动。我们希望尝试一种更有趣、更具参与感的方式。

受到动漫和奇幻作品中「冒险者公会」的启发，我们将校园志愿服务重新设计为一套**委托任务系统**：

- 🗡️ **接受委托** — 学生像冒险者一样，寻找并领取校园内的志愿服务任务
- 📜 **完成任务** — 通过实际参与志愿活动完成对应的委托
- 🎁 **获取奖励** — 通过任务奖励和正向反馈激励学生持续参与
- ⏳ **记录时长** — 将志愿活动与服务时长记录相结合
- 🏫 **校园管理** — 帮助学校更方便地组织志愿活动、管理任务与记录志愿服务情况

我们希望通过游戏化设计，让志愿服务不再只是一项需要完成的要求，而是学生愿意主动参与的校园活动。

> **Every volunteer is an adventurer. Every act of kindness is a quest worth completing.**
>
> 每一位志愿者都是冒险者，每一次善意的付出都是值得完成的委托。

## 🎯 Project Goals | 项目目标

The project was designed around three main goals:

**1. Make Volunteering More Engaging**

Introduce game-inspired quest mechanics to encourage students to participate in community service.

**2. Simplify Volunteer Management**

Provide a centralized platform for organizing volunteer opportunities and supporting the tracking of service hours.

**3. Encourage Positive Community Impact**

Use rewards and a sense of achievement to recognize students' contributions and make volunteering a more enjoyable experience.

## 🧩 Core Concepts | 核心设计

### 📜 Quest Board — 委托公告板

将校园志愿者活动以「委托」的形式展示，让学生能够了解任务内容并选择感兴趣的活动。

### ⚔️ Quest Participation — 委托参与

围绕任务领取、参与和完成建立志愿活动流程，将线下的志愿行动与线上的任务体验联系起来。

### 🎁 Rewards & Motivation — 奖励与激励

通过游戏化奖励和完成任务后的正向反馈，让志愿服务更有成就感，鼓励学生持续参与。

### ⏳ Volunteer Hour Tracking — 志愿时长记录

将任务参与情况与志愿服务时长相结合，为学校整理和管理学生的志愿服务记录提供支持。

### 🏫 School Administration — 校园管理

从学校管理的角度组织志愿服务任务，减少传统活动管理与信息整理的复杂度。

## 🚀 Getting Started | 本地运行

This repository preserves the frontend source code of the former project.

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

`git clone https://github.com/canw08/adventurer.git`

Navigate into the project directory:

`cd adventurer`

Install dependencies:

`npm install`

Start the development server:

`npm run dev`

Create a production build:

`npm run build`

**Note:** Starting the frontend development server does not necessarily restore the original application. Some functions may require backend services, APIs, or configurations that are no longer available.

## 📦 Project Status | 项目现状

**This project is no longer in operation.**

Adventurer's Guild was originally developed for a high school volunteering environment. Following the end of its operation, the repository was made public to preserve the project and share its design and implementation.

The original service is no longer maintained, and this repository is not intended to be a production-ready volunteer management system.

### Why Make It Public?

Although the project is no longer active, it represents an exploration of how software and game design can make real-world activities more engaging.

By making the repository public, we hope to:

- Preserve the development work and original ideas
- Share an example of gamification applied to education and volunteering
- Provide a reference for frontend development and application design
- Inspire future projects that encourage community participation

**This repository is maintained as a historical project and portfolio reference rather than an active service.**

## 💭 Behind the Idea | 设计理念

游戏之所以能够吸引人，不仅仅是因为奖励，更因为它赋予了行动明确的目标、即时的反馈与完成挑战后的成就感。

我们希望把这些体验带入现实校园。

当一次志愿服务被包装成一份委托，当付出的时间能够被记录，当帮助他人也能够获得认可，原本普通的校园活动就有机会变成一次值得期待的冒险。

**Technology should not only solve problems. It can also make meaningful experiences more engaging.**
